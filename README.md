# Agente de Prospecção

Projeto em preparação. O objetivo e as funcionalidades da primeira versão ainda serão definidos.

## Desenvolvimento

Todos os arquivos do projeto devem ficar nesta pasta. Arquivos de ambiente, credenciais e chaves devem permanecer apenas no ambiente local, fora do versionamento.

Após cada etapa funcional: executar os testes pertinentes, revisar os arquivos e o diff em busca de informações sensíveis, criar um commit e executar `git push origin main`.

O comando para executar o site e a visualização no navegador integrado serão configurados junto com a primeira versão da aplicação.
